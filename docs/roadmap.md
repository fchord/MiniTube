# MiniTube 分期路线

完整蓝图一次画完，实现严格分期。MVP 停在 **Phase 2**（身份 + 频道 + 长视频点播）。短视频与直播只预留字段与契约，不开放入口。

## Phase 0 — 契约（已完成）

- 冻结领域模型、客户端策略、本路线图
- OpenAPI 初稿 + PostgreSQL 表结构草案
- 仓库布局：`api/`、`web/`、`app/`、`worker/`、`docs/`

## Phase 1 — 身份与频道（已完成）

- 注册（用户名 + 邮箱验证）、登录、登出、资料、头像
- 自动创建默认频道；创建 / 编辑更多频道
- 订阅 / 取消订阅频道
- 用户主页列出频道；频道页为订阅与内容墙

出验收：未登录可看公开频道页骨架；登录用户能改资料、开第二频道并订阅别人。

## Phase 2 — 长视频点播（已完成）

- 直传对象存储、转码状态、HLS 多分辨率播放
- 先单音轨 + 可选软字幕，再扩展多音轨
- 播放页、观看记录、收藏（含稍后再看）、评论、点赞

出验收：注册 → 默认频道 → 上传一条长视频 → 转码完成 → Web 与 Flutter 都能播放。

**最小完整产品停在这里。** 短视频、直播、社交帖入口不对终端用户开放。

## Phase 3 — 社交帖（已完成）

- 发帖（多图 + 字数上限）、时间线、评论与点赞
- 用户主页与频道页展示帖子
- 订阅频道的帖子 Feed
- 可选 @ 视频

## Phase 4 — 短视频（已完成）

- 同一 `videos` 管线，`kind = short`
- Web 竖滑 Feed：队列由前端持有；频道入口 `?ch=` 绕圈，其它入口随机补片
- 预加载与硬解窗口：**1+1+3**（负向 1 + 当前 + 正向最多 3），硬解不够则降正向 k
- 默认静音；静音按钮 / `M` 管声音；点画面只播放暂停；底边只读进度条
- `/shorts/hwtest` 最多 10 路硬解压测（约 1fps 上屏）
- 约定见 [`shorts-playback.md`](shorts-playback.md)

## Phase 5 — 直播（进行中）

入口已开放：创建直播、RTMP 推流、HLS 观看、SSE 聊天。Origin 从 MediaMTX 换成 **SRS**（进程不随一路 EOF 退出）。

关播与录播约定（本版已落地）：

- 直播 HLS 全量落盘（EVENT，窗口约 24h）；`hls_cleanup off`，删除由 MiniTube 管，停服务不删回看
- EOF / unpublish：强制关当前段并补 `EXT-X-ENDLIST`；同一播放 URL 结束后当回看，不另转普通长视频 Feed
- 推流已停且 **1h 无 HLS 拉流** 才标 `ended`；进度本地记住，回来可 seek
- 推流：`rtmp://主机:1935/live/{ingestKey}`（建议短 GOP）

未做：Flutter 直播、断流重连窗口、多码率转码。

## Phase 6 — 平台能力

- 搜索、基础推荐（先订阅时间线 + 热门 + 相关）
- 通知、审核后台、嵌入播放器、创作者数据

## 第一年默认不做

- 八端原生重写
- 复杂个性化推荐
- 弹幕全站、电商、完整广告 SDK
- 把宽高比写成类型约束
