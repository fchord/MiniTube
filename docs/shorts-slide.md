# 短视频竖滑过渡动画

本文记录 `/shorts` 上下切条的位移曲线：坐标约定、试过的 \(e(p)\)、当前实现，以及尚未做的过冲回弹。实现以 [`api/internal/httpapi/shorts.html`](../api/internal/httpapi/shorts.html) 为准。队列、硬解窗口与播放引擎见 [`shorts-playback.md`](shorts-playback.md)。

## 坐标与时间

键盘 ↑↓（以及滚轮触发的 `step`）在时长 \(T\) 内把画面滑过一整屏。令

\[
p = \frac{t}{T} \in [0,1],
\]

其中 \(t\) 为动画已经过的时间。当前键盘 \(T = 560\,\mathrm{ms}\)（`SLIDE_KEY_MS`）。

位移用无量纲 \(e(p)\) 表示走完一屏的比例：

\[
s(p) = D \cdot e(p),\qquad D \in \{+1,-1\}.
\]

代码里的 `shift` 即 \(s\)。向下切 \(D=+1\)，向上切 \(D=-1\)。对 \(p\) 的导数是 \(e'(p)\)；对真实时间的速度是

\[
v(t) = \frac{\mathrm{d}s}{\mathrm{d}t} = \frac{D}{T}\,e'(p).
\]

希望的形状是慢—快—慢：

\[
e(0)=0,\quad e(1)=1,\quad e'(0)=e'(1)=0.
\]

中点 \(|e'(1/2)|\) 越大，中间越「爽」；\(p\) 靠近 \(0\) 或 \(1\) 时 \(e\) 越贴端点，头尾越「黏」。

`applyTransforms(idx, shift)` 把相邻两条叠在竖方向上：

| 条 | CSS `pos`（单位：屏高） |
| --- | --- |
| 当前（滑出） | \(-s\) |
| 下一条（\(s>0\)） | \(1-s\) |
| 上一条（\(s<0\)） | \(-1-s\) |

因此 \(s=1\) 时新片居中、旧片整屏移出。\(p=1\) 时 `finishSlide` 把 `shift` 钉成 \(0\)，换 `baseIdx`，再 `activate` 听路。

手指甩开仍走另一条曲线：`easeOutSine`，\(T=420\,\mathrm{ms}\)（`SLIDE_FLICK_MS`），

\[
e_{\mathrm{out}}(p)=\sin\Bigl(\frac{\pi p}{2}\Bigr),\qquad e_{\mathrm{out}}'(0)=\frac{\pi}{2}.
\]

出手就是最大速度，再减速。回弹不到位用 `SLIDE_BACK_MS = 380\,\mathrm{ms}\) 的同一条 `easeOutSine`。后文只讨论键盘这条 \(e(p)\)。

## 一层正弦

最早的键盘曲线（`easeInOutSine`）：

\[
e(p)=\frac{1-\cos(\pi p)}{2},\qquad e'(p)=\frac{\pi}{2}\sin(\pi p),\qquad e''(p)=\frac{\pi^{2}}{2}\cos(\pi p).
\]

| \(p\) | \(e\) | \(e'\) |
| --- | --- | --- |
| \(0\) | \(0\) | \(0\) |
| \(1/2\) | \(1/2\) | \(\pi/2 \approx 1.57\) |
| \(1\) | \(1\) | \(0\) |

起点速度为 \(0\)，但 \(e''(0)=\pi^{2}/2\) 是全程最大加速度，头几帧就会冲起来。把 \(T\) 从 \(840\,\mathrm{ms}\) 收到 \(560\,\mathrm{ms}\) 后，真实速度与加速度按 \(1/T\)、\(1/T^{2}\) 变大，更快，也更像急刹停住。

## 开方余弦（已弃）

为了两端更趴、中间更陡，试过保号开方（版本 `20260918a`）：

\[
e(p)=\frac{1}{2}-\frac{1}{2}\,\mathrm{sgn}\bigl(\cos(\pi p)\bigr)\,\bigl|\cos(\pi p)\bigr|^{1/2}.
\]

端点仍对：\(e(0)=0\)，\(e(1/2)=1/2\)，\(e(1)=1\)，且 \(e'(0)=0\)。前 \(25\%\) 时间大约只走出 \(8\%\) 屏（一层正弦约 \(15\%\)）。

问题在中点。\(\sqrt{|x|}\) 在 \(x=0\) 的导数是 \(1/(2\sqrt{|x|})\)，故

\[
\lim_{p\to (1/2)^{-}} e'(p) = +\infty,\qquad \lim_{p\to (1/2)^{+}} e'(p) = +\infty.
\]

位移连续，速度有奇点。\(560\,\mathrm{ms}\)、\(60\,\mathrm{Hz}\) 大约 \(33\) 帧，奇点附近 \(1\sim 2\) 帧会一下子划过约 \(20\%\) 屏，中间闪一下。凡 \(\alpha<1\) 的 \(|\cos(\pi p)|^{\alpha}\) 都有此奇点；\(\alpha=1\) 才退回一层正弦。

## 正弦套一层

把一层正弦再喂给自己（版本 `20260918b`，`easeInOutSine2`）：

\[
e_{2}(p)=e\bigl(e(p)\bigr)=\frac{1-\cos\bigl(\pi\,e(p)\bigr)}{2}.
\]

链式法则：

\[
e_{2}'(p)=e'\bigl(e(p)\bigr)\,e'(p)=\frac{\pi}{2}\sin\bigl(\pi e(p)\bigr)\cdot\frac{\pi}{2}\sin(\pi p).
\]

中点 \(e(1/2)=1/2\)，\(\sin(\pi/2)=1\)，故

\[
e_{2}'\Bigl(\tfrac{1}{2}\Bigr)=\Bigl(\tfrac{\pi}{2}\Bigr)^{2}\approx 2.47
\]

约为一层正弦峰值的 \(1.57\) 倍，且有限。起点仍有 \(e_{2}'(0)=0\)，且 \(e_{2}''(0)=0\)。\(p\to 0\) 时 \(e(p)\sim (\pi p)^{2}/4\)，从而 \(e_{2}'(p)\propto p^{3}\)、\(e_{2}(p)\propto p^{4}\)，比一层正弦贴零。实感：中间峰值合适，开头仍偏快。

## 倒过来的二次 / 三次（未上线）

曾考虑用多项式顶替 \(\cos\)，例如前半 \(p\in[0,1/2]\) 取 \(f(p)=(1-2p)^{n}\)（\(n=2,3\)），再

\[
e(p)=\frac{1}{2}-\frac{1}{2}f(p).
\]

余弦在 \(p=0\) 处导数为 \(0\)（\(\sin 0=0\)）。\((1-2p)^{2}\)、\((1-2p)^{3}\) 在 \(p=0\) 的导数非 \(0\)，对应 \(e'(0)=2\) 或 \(3\)，起步更快，和「先慢」相反。

即便改成平坦起步的二次易入 \(e=2p^{2}\)（\(p\le 1/2\)），也是 \(p^{2}\) 量级，比套层正弦的 \(p^{4}\) 更冲。

## 当前：五次 + 六次

版本 `20260918c`，`easeInOutPoly`。目标：中点峰值锁成 \(e_{2}'(1/2)\)，开头比 \(e_{2}\) 更贴零。

前半 \(p\in[0,1/2]\) 用

\[
e(p)=A p^{5}+B p^{6}.
\]

这自动满足 \(e(0)=e'(0)=e''(0)=e'''(0)=0\)。再用两个条件定系数：

\[
e\Bigl(\tfrac{1}{2}\Bigr)=\tfrac{1}{2},\qquad e'\Bigl(\tfrac{1}{2}\Bigr)=k,\qquad k=\Bigl(\tfrac{\pi}{2}\Bigr)^{2}.
\]

解得

\[
A=96-16k,\qquad B=32k-160.
\]

后半对称：

\[
e(p)=1-e(1-p)\qquad\bigl(p\in[1/2,1]\bigr).
\]

在 \(p=1/2\) 处 \(e\) 与 \(e'\) 两侧连续。\(p\to 0\) 时 \(e(p)\propto p^{5}\)，比 \(e_{2}\) 更黏；前 \(20\%\) 时间大约只走出 \(1.3\%\) 屏（\(e_{2}\) 约 \(2.3\%\)）。中点 \(|e'|\) 与套层正弦相同。

代码：

```javascript
function easeInOutPoly(t) {
  const k = (Math.PI * Math.PI) / 4;
  const A = 96 - 16 * k;
  const B = 32 * k - 160;
  function rise(p) { return p * p * p * p * p * (A + B * p); }
  if (t <= 0.5) return rise(t);
  return 1 - rise(1 - t);
}
```

## 约束

在 \(T\) 固定、中点峰值固定时，再把头放慢，只能把行程挤到靠近 \(1/2\) 的加速段。极端就是开方余弦那种中点奇点。若开头仍嫌快，应加长 \(T\)，而不是再抬中点峰值。

## 尚未做：过冲回弹

当前 \(e(1)=1\) 且 \(e'(1)=0\)：正好停在目标上，像电机到位断电。人眼更习惯惯性带过目标一点点，再拉回来。

仍用 \(s(p)=D\cdot e(p)\)，只让 \(e\) **先大于 \(1\) 再回到 \(1\)**。例如 \(e=1.04\) 时，下一条的 `pos = 1-s = -0.04`，越过居中约 \(4\%\) 屏高，再回到 \(0\)。\(p=1\) 时仍要 \(e(1)=1\)，然后才 `finishSlide` / `activate`。过冲发生在动画过程中，不改落地时机。

不要用标准 `easeInOutBack`：它在起点会先往反方向缩（anticipation），切条会先倒退。

两条可实现的路，与上面的快慢分配正交（可叠在现在的 `easeInOutPoly` 之后，或换成一条本身带过冲的 \(e\)）：

1. **三次贝塞尔**，起点切线水平、只在终点过冲。控制点大约 \((0,0)\)、\((0.40,0)\)、\((0.20,1.12)\)、\((1,1)\)。\(P_1\) 的 \(y=0\) 使 \(e'(0)=0\)；\(P_2\) 的 \(y>1\) 使曲线越过 \(1\) 再贴回。过冲大约是屏高的百分之几，不必等于 \(0.12\)。
2. **欠阻尼弹簧** \(\ddot x + 2\zeta\omega\dot x + \omega^{2}(x-1)=0\)，初值 \(x(0)=\dot x(0)=0\)。\(\zeta\approx 0.7\) 时阶跃过冲约 \(5\%\)，基本只弹一次。时长上弹簧永不静止，需在 \(|x-1|\) 与 \(|\dot x|\) 足够小时截断，或把 \(T\) 取成与 \(\omega,\zeta\) 匹配的沉降时间。

过冲幅度建议屏高的 \(3\%\sim 6\%\)：再小看不出回弹，再大像弹跳。手指甩若也要同一语感，应改成「慢起 + 终点过冲」，用当前手速去拟合 \(T\)，而不是继续 `easeOutSine`。
